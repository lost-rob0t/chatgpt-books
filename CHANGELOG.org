#+title: Changelog

* Unreleased
** Added
- Initial private Org-first nine-book publishing bootstrap.
- Generated =flake.lock= via =nix flake lock= on a Nix-capable host (issue #3). The lockfile pins =nixpkgs/nixos-unstable= and is reproducible.
- EPUB publication regression inspection for package accessibility metadata, stable IDs/internal links, citations, footnotes, MathML, tables/code, SVG/PNG/JPEG media, captions, meaningful alt text, Unicode, and cover metadata (issue #4).
- Explicit fixture accessibility metadata and an accessibility/failure-diagnostics policy grounded in W3C EPUB Accessibility 1.1.
- A Pandoc Org-reader contract test that detects upstream AST changes affecting =:ID:=, =:CUSTOM_ID:=, and Figure-level alt normalization.
- =tools/prepare-org-for-pandoc=, which creates an export-only temporary Org copy containing deterministic =org-id-<ID>= aliases and rewritten same-document =id:= links while leaving canonical Org untouched.
- Issue #27: initial standalone =books/prolog-llms= curriculum scaffold, project sequence, research architecture, manuscript contract, and publication metadata.

** Changed
- =elisp/chatgpt-books-roam.el= now forward-declares Org-roam variables (=org-roam-directory=, =org-roam-db-location=, =org-roam-capture-templates=, =org-roam-db-autosync-mode=) so the project package and its ERT suite behave correctly before =(require 'org-roam)= executes. =chatgpt-books-roam-restore= now reads =org-roam-db-autosync-mode= with =boundp=, fixing a =void-variable= failure exposed by the minimal Nix devShell.
- Fixture and per-book builds now prepare stable Org-ID aliases before invoking Pandoc, because Pandoc 3.10.1 discards =:ID:= from the Header AST when =:CUSTOM_ID:= is also present.
- Fixture and per-book EPUB3 builds now pass =--mathml= explicitly because Pandoc 3.10.1 no longer forces MathML for EPUB3 output.
- =tools/pandoc-org-id.lua= is intentionally limited to Figure-alt normalization; it no longer tries to reconstruct stable IDs after the Org reader has discarded information.
- The publishing fixture now includes deterministic JPEG coverage in addition to SVG and PNG.
- Issue #27: structural validation no longer rejects the repository merely because the book set grew beyond the original nine. Required principal books are enforced, additional active books receive the same structural checks, and the explicitly paused StarLang scaffold remains discoverable without pretending it is an active manuscript pipeline.
- Root book inventory now records ten principal books plus the paused in-tree StarLang scaffold and documents Prolog-family editorial boundaries.

** Fixed
- ERT =chatgpt-books-roam-state-roundtrip= no longer depends on Org-roam being pre-loaded; the alphabetical test run order still lets CI's real Org-roam sync test load the package first, but the roundtrip test is now robust on hosts without Org-roam installed.
- Same-document Org =id:= links now resolve to deterministic EPUB fragment aliases without replacing existing =:CUSTOM_ID:= targets.
- Org IDs beginning with digits no longer depend on Pandoc's writer-specific identifier rewrite; all publication aliases use one stable namespace.
- Math expressions remain semantic MathML under Pandoc 3.10.1 instead of silently falling back to the writer's plain math method.
- Issue #27: generic =books-ci= structural validation no longer fails solely because =books/starlang= exists outside the original bootstrap book set.
