#+title: Project 1 -- Foundational Research Harness

* Purpose
This is an executable research harness for Project 1, not chapter prose and not a replacement StarIntel runtime.

It currently exercises:
- Experiment E: a pinned StarIntel 0.9 conformance smoke matrix.
- Experiment D0: a narrow synthetic provenance-manifest round trip used to verify the harness shape.
- Experiment D1: a frozen official GLEIF public-source extract mapped into a canonical StarIntel =org= record with byte hashes and provenance reconstruction checks.
- D2A: official GLEIF current-format sample =org= + =relation= adapter-shape coverage, including honest unresolved endpoints where the sample bundle lacks matching Level 1 records.
- Experiment D: a frozen factual as-of primary GLEIF API snapshot mapped offline into three entity-closed =org= documents and two =relation= documents with source/hash provenance reconstruction.

Experiments A--C remain UNTESTED.

* Canonical boundary
The harness materializes the canonical schema from:

- repository: =lost-rob0t/starintel-gpt-auto-dig=

- Git blob SHA-1: =b26d62644c675e2d55f4ea95f8ec207cfb08ae9a=

The fetched bytes are rejected unless their Git blob identity matches exactly. This avoids silently following a moving branch while also avoiding a second hand-maintained StarIntel schema in this book.

StarIntel remains =schema_version: "0.9.0"=. The separate top-level document =version= is integer =1= in the research fixtures. Nothing in this harness promotes the StarIntel specification to 1.0.

* Claim-status rules
- A CI invocation that actually executes a case may be recorded as TESTED.
- A failing invocation is FAILED and remains part of the research record.
- D0 does not prove public-source provenance.
- D1 proves only the earlier frozen contact-page extract path.
- D2A proves the Tier A adapter shape and unresolved-endpoint semantics, not current factual relationships.
- Full D proves reproducibility and canonical validation for the frozen Tier B as-of observation; it does not claim those relationships persist forever.
- Cross-language Python/Nim/Common Lisp conformance remains UNTESTED here.
- Experiments A--C remain UNTESTED until their split rules are predeclared and actual measurements run.

* First observed failure
The first CI execution on 2026-08-14 rejected the supposed-valid fixture because top-level StarIntel =version= is an integer with minimum 1, not the schema-version string. The harness was corrected to =version: 1= and retains the original mistake as a negative regression case. This is exactly why implementation claims stay UNTESTED until exercised against the canonical schema.
