* Major Projects
** Project 1 -- Investigation Dataset Pipeline
:PROPERTIES:
:ID:       a289a81e-a645-52da-bcb6-6e72b9848a72
:END:
Purpose: Build a reproducible public/synthetic StarIntel-style data pipeline with validation, feature engineering, splits, provenance, and quality reports.
Learning outcomes: integrate multiple chapter concepts; make architecture/test/provenance tradeoffs explicit.
Prerequisites: the chapters listed in OUTLINE.org before this project's integration point.
Relevant chapters: staged across the curriculum; final integration is dependency-gated in ROADMAP.org.
Architecture: split domain logic, interfaces, persistence/external boundaries, tests, and observability rather than one monolith.
Implementation language/tooling: selected to match the book subject; dependencies must be pinned/reproducible.
External dependencies: public/synthetic data and primary documentation only unless a later issue records an approved dependency.
Tests: unit + scenario/regression tests; add property/integration/performance tests when the architecture warrants them.
Failure scenarios: invalid input, boundary failure, contradictory/edge cases, and one operational/debugging failure.
Visuals: at least one architecture or execution-flow figure plus traces/plots when useful.
Research requirements: verify version-sensitive APIs and theoretical claims from primary sources before implementation.
Expected deliverable: runnable implementation, tests, design notes, diagrams, exercises, and an exportable project chapter.
