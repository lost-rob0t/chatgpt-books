** StarIntel boundary
All inspected locks identify schema =0.9.0= and the same canonical commit. Locked manifest: profile =starintel-core=, additive revision =0.9.0+fields.20260726.2=, 50 dtypes, base+expansion materialization before validation. =DOCUMENTED=.

Required common fields: =_id dataset dtype schema_version version date_added date_updated sources evidence data=. Top-level and dtype =data= are closed; =extensions= is open/namespaced. Existing source/provenance/lineage sections already cover URI, retrieval time, hashes, license, transforms, environment and derivation, so Book 1 should adapt rather than clone the schema.

** Project 1 fixture
GLEIF Level 1/2 is preferred: official CC0 terms and strong entity/identifier/address/status/parent-child semantics. CFPB remains a later structured-data exercise; initial bundle should avoid consumer narratives. Wikidata is a CC0 fallback.

Design =EXPERIMENTAL=: tiny deterministic frozen GLEIF slice + fixed-seed synthetic observations adding repeated entities, aliases, exact/near duplicates, missingness, contradictions, short synthetic text, labels, source variation and relations. Record snapshot/URI/hash/extraction rule/IDs/license; tests never require live upstream.

** Splitting/provenance/toolchain
Random/stratified splits do not protect correlated records. Proposed planner =EXPERIMENTAL=: cutoff first; deterministic entity/duplicate groups; no group crossing; no post-cutoff training information; spanning groups wholly later or purged with reason; optional publisher holdout; exact split manifest. Learned preprocessing fits on training only.

Per record use canonical source/provenance/lineage/temporal/quality fields. Dataset manifest records source snapshot/hashes, transform parameters, StarIntel lock/revision, code/environment, seeds, split membership, exclusions, label policy, warnings/license/counts. Borrow W3C PROV concepts without adding RDF infrastructure.

Proposed stack =UNTESTED=: Python 3.13.x, NumPy 2.5.x, pandas 3.0.x, scikit-learn 1.9.x, Matplotlib 3.11.x, PyArrow 25.0.x if Parquet, jsonschema 4.25.x, pytest 9.1.x, optional Hypothesis 6.x. PyTorch 2.13.x is for later chapters; Pydantic must not redefine StarIntel. No embedding dependency needed.
