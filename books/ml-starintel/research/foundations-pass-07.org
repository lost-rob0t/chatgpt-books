* Implementation implications
1. Project 1 should preserve three fixture tiers:
   - Tier A: official illustrative/format fixtures for parser/adapter edge cases;
   - Tier B: frozen primary factual as-of observations for provenance/integration examples;
   - Tier C: deterministic synthetic fixtures for controlled ML ground truth and leakage experiments.
2. Missing source-graph closure must be explicit. Do not synthesize entity facts merely to make a graph look complete.
3. Full-D ordinary tests are offline. Live GLEIF acquisition is a separate refresh/integration action.
4. Source provenance keeps both raw-response hashes and a deterministic canonical-JSON hash; the committed source identity is the canonical parsed snapshot.
5. StarIntel remains =schema_version: "0.9.0"= with separate integer document =version: 1=. This work does not imply or create StarIntel 1.0.
6. No CouchDB, RabbitMQ, actor supervision, generic ingest, or generic StarIntel validation semantics were copied into the book project.
