* Tests-first execution
The acceptance tests were committed before the implementation in this pass. They require:
- canonical lexical pair ordering;
- exact pair/source equality under reversed and seeded-permuted input order;
- exact-hash candidate production independent of LSH retrieval;
- exact Jaccard verification before duplicate-component closure;
- final duplicate-component equality with the pre-existing all-pairs Tier C oracle;
- qualifying-pair recall 1.0 on Tier C;
- fewer candidate pairs than all possible record pairs;
- explicit =datasketch= scheme, threshold, seed and =num_perm= parameters.

The implementation then added three candidate sources under the pass-11 contract:
1. =exact-hash=: buckets of the existing Experiment C normalized-text SHA-256;
2. =block=: deterministic rare-token blocking using corpus document frequency, lexical tie-breaking and two selected tokens per record;
3. =minhash-lsh=: =datasketch==2.0.0= MinHash/LSH with =scheme="affine32"=, =seed=1729=, =num_perm=128= and candidate threshold =0.80=.

The blocking rule is TESTED only as a deterministic candidate producer on Tier C. It is not promoted to a general-quality claim for heterogeneous public StarIntel records. Labels and future-only features are not inputs to the blocker.

Every proposed pair is canonicalized and deduplicated across candidate sources. Exact normalized token-set Jaccard =>= 0.80= remains the only near-duplicate edge predicate before transitive component closure.

* Failure and adversarial notes
- LSH false negatives remain possible in principle. The Tier C recall result does not remove that risk on a new corpus.
- Deterministic blocking can miss pairs whose useful lexical keys diverge. Unioning it with LSH helps candidate recall but is not proof of completeness.
- Candidate false positives are safe for duplicate truth because exact verification rejects them before union-find closure; false negatives are the dangerous failure mode.
- A transitive duplicate component can be wrong if even one required true edge is never proposed. Larger-corpus evaluation therefore must compare candidate recall against an exact or otherwise defensible oracle subset, not merely inspect final group sizes.
- The current Python dependency file pins direct dependencies but not the entire transitive environment; the reproducibility contract remains incomplete.
