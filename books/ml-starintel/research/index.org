* Research questions
- Which primary sources define the foundational concepts?
- Which behavior is version-sensitive in the current toolchain?
- Which claims require reproduction/benchmarking rather than citation alone?
- Which StarIntel document/schema boundary should the ML projects target?
- Which split policies avoid evaluation contamination across related entities, time, duplicate clusters, graph edges, and source lineage?
- Which provenance facts belong on canonical StarIntel records versus dataset-build manifests?
- Which canonical-schema assumptions survive executable validation before Project 1 data is admitted?
- Which public-source bytes can be frozen so provenance and evaluation remain reproducible when upstream GLEIF data changes?
- Which official GLEIF current-format sample records form the smallest deterministic Level 1 + Level 2 ownership fixture for Project 1?
- Which GLEIF artifacts are illustrative format fixtures versus factual public observations suitable for provenance/evaluation claims?
- After full public-source provenance is proven, how much do random, temporal, entity-group, exact-duplicate, and near-duplicate split policies distort measured performance on controlled StarIntel-style data?
- How should entity, duplicate, source-lineage, graph-group, time-cutoff, and feature-availability constraints compose into one deterministic split planner for real StarIntel-style datasets?
- Which composite components straddle a real temporal cutoff, and does the proposed fail-closed policy remain usable on non-synthetic public data?
- Can scalable candidate generation preserve the exact Experiment C near-duplicate predicate while reducing the comparison set deterministically?
- Which predeclared MinHash/LSH parameter grid and frozen public corpus can evaluate recall, reduction, runtime and component agreement without post-hoc tuning?
- How should the final validated composite groups be handed to scikit-learn grouped splitters without weakening temporal/admissibility invariants?
- What dependency-lock policy is sufficient to reproduce Project 1 beyond direct top-level pins?
