* Implementation result
Added =research-harness/composite_split_planner.py= as a pure planner module. It:
- canonicalizes record/edge IDs;
- composes hard must-link constraints through deterministic disjoint-set/equivalence closure;
- assigns the lexicographically smallest record ID as =composite_group_id=;
- preserves edge provenance in component diagnostics;
- checks strict cutoff straddling separately from grouping;
- checks feature =available_at= against =prediction_at=;
- audits train/test overlap for composite groups and selected hard-rule fields;
- raises =SplitInfeasible= rather than silently moving rows when a strict constraint is violated.

This module has no CouchDB, RabbitMQ, HTTP ingest, actor supervision, durable outbox, search, or StarIntel storage code.
