** Processes -- Erlang System Documentation v29.0.6, failure relationships
- URL :: https://www.erlang.org/doc/system/ref_man_processes.html
- Authority :: Official Erlang/OTP reference documentation.
- Retrieved :: 2026-09-16.
- Relevant sections :: Links; Sending Exit Signals; Receiving Exit Signals; Monitors; signals and signal ordering.
- Used for :: Chapters 7--9 and Project 1 checkpoint B.
- Result :: Links are bidirectional and emit exit signals when a participant terminates. Whether an exit terminates a receiver, is dropped, or becomes an =EXIT= message depends on the trap-exit state, reason, sender, link flag, and current link state. Monitors are one-way and independently identified; process termination produces a correlated =DOWN=, and monitoring a nonexistent process produces =noproc=.
- Claim status :: DOCUMENTED.

- URL :: https://www.erlang.org/doc/apps/erts/erlang.html
- Authority :: Official Erlang/OTP ERTS reference documentation.
