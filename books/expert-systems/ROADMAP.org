* Phase 0 -- scope
DONE bootstrap purpose, audience, topics, and project boundaries.
* Phase 1 -- foundational research
IN-PROGRESS verify theory, current toolchain behavior, canonical implementations, and source bibliography.

Foundation slice A researched production-system structure, naive condition matching, variables/bindings, joins, and provenance using Forgy's OPS5/RETE material, current official CLIPS documentation, and authoritative Linux/systemd sources for the technical fixture.

Foundation slice B freezes the next executable semantic boundary: mutable working-memory identity/occurrences, stable productions/activations, naive complete-rematch forward chaining, deterministic agenda policy, and explicit refraction. It remains intentionally upstream of incremental alpha/beta/RETE, truth maintenance, uncertainty, persistence, and benchmarks.
* Phase 2 -- curriculum
Review sequence and cross-book dependencies.
* Phase 3 -- detailed outline
Turn each chapter item into research questions, examples, exercises, and asset requirements.
* Phases 4--6 -- progressive chapters/projects
Implement projects in the order listed in PROJECTS.org; later projects depend on foundations from earlier ones.

Project 1 milestone A is the merged semantic baseline: literal matcher -> variables/bindings -> deterministic multi-condition joins with supporting fact identities.

Project 1 milestone B is the active dependency-ready slice: working-memory assertion/retraction and occurrence identity -> stable productions/complete activations -> conflict set/agenda -> deterministic conflict resolution -> bounded forward chaining -> occurrence-aware refraction. The implementation deliberately rematches completely after every firing so it remains a transparent correctness oracle.

Only after milestone B is reviewed and verified should Project 1 proceed to incremental matching -> alpha/beta memories -> join/token/production nodes -> RETE-like propagation. Truth maintenance follows the incremental engine and must preserve explicit evidence/support identity.

The last project is the major integrated capstone and depends on the previous project/tooling slices.
