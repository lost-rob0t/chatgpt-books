* Phases 4--6 -- progressive chapters/projects
Implement projects in the order listed in PROJECTS.org; later projects depend on foundations from earlier ones.

Project 1 milestone A is the merged semantic baseline: literal matcher -> variables/bindings -> deterministic multi-condition joins with supporting fact identities.

Project 1 milestone B is also merged: working-memory assertion/retraction and occurrence identity -> stable productions/complete activations -> conflict set/agenda -> deterministic conflict resolution -> bounded forward chaining -> occurrence-aware refraction. The implementation deliberately rematches completely after every firing so it remains a transparent correctness oracle.

Project 1 milestone C is ACTIVE as issue #79 / PR #80: incremental positive-pattern matching -> alpha memories -> beta memories -> join/token/production nodes -> RETE-like assertion/retraction propagation. The worker implementation must preserve milestone-B activation/refraction/agenda semantics through executable equivalence regressions before any performance comparison is attempted. It deliberately excludes negative/existential conditions, truth maintenance, uncertainty, persistence, TREAT implementation, and benchmark claims.

After editorial acceptance of milestone C, Project 1 proceeds to truth maintenance: stable justifications/support dependencies, cascading removal of unsupported derived facts, and explanation-facing dependency identity. Contradiction/counterevidence policy follows that semantics rather than being hidden inside matching caches.
