* Phase 0 -- scope
DONE bootstrap purpose, audience, topics, and project boundaries.
* Phase 1 -- foundational research
IN-PROGRESS verify theory, current toolchain behavior, canonical implementations, and source bibliography.

Foundation slice A researches production-system structure, naive condition matching, variables/bindings, joins, and provenance using Forgy's OPS5/RETE material, current official CLIPS documentation, and authoritative Linux/systemd sources for the technical fixture. It deliberately leaves working-memory mutation, agenda/refraction, incremental networks, truth maintenance, uncertainty, and persistence for dependency-ordered follow-up research.
* Phase 2 -- curriculum
Review sequence and cross-book dependencies.
* Phase 3 -- detailed outline
Turn each chapter item into research questions, examples, exercises, and asset requirements.
* Phases 4--6 -- progressive chapters/projects
Implement projects in the order listed in PROJECTS.org; later projects depend on foundations from earlier ones.

Project 1 milestone A is the semantic baseline: literal matcher -> variables/bindings -> deterministic multi-condition joins with supporting fact identities. The next implementation milestone is mutable working memory -> real productions -> forward chaining -> conflict set/agenda -> explicit conflict resolution/refraction. Only after that baseline is verified should incremental alpha/beta and RETE-like machinery begin.
* Phase 7 -- capstone
The last project is the major integrated capstone and depends on the previous project/tooling slices.
* Phase 8 -- technical review
Re-run all examples/tests/benchmarks and verify citations.
* Phase 9 -- editorial and visual review
Prose, navigation, diagrams, accessibility, and cover.
* Phase 10 -- EPUB release
Production build + EPUBCheck + private artifact/release.
