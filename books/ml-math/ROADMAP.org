* Phase 1 -- foundational research
IN-PROGRESS verify theory, current toolchain behavior, canonical implementations, and source bibliography.

Foundation pass A covers the arithmetic-to-vector dependency chain, author-maintained linear-algebra sequencing, the current NumPy numerical oracle, and Python floating-point primitives used by Project 1 checkpoint A.

Foundation pass B covers matrix shape/indexing, =Ax= as row dot products and column linear combinations, compatible =AB= multiplication, composition/identity/noncommutativity/associativity, two-dimensional linear-transformation geometry, and the finite-precision boundary between algebraic associativity and actual floating-point execution. The source record also captures the current NumPy 2.5 =matmul= and =ndarray.shape= behavior used by the oracle tests plus the official Python floating-point guidance used by the numerical failure lab.

Foundation pass C covers the calculus/derivatives dependency: secant-to-tangent derivative definition and scalar chain rule against MIT OpenCourseWare 18.01SC, partial derivatives/gradients/directional derivatives against MIT OpenCourseWare 18.02SC, and the sampled finite-difference oracle boundary against official NumPy 2.5 =gradient= documentation. The teaching lab keeps exact derivative claims separate from finite-difference TESTED evidence and carries forward the documented Python floating-point step/cancellation boundary.

Project 2 pass D is active. It checks least-squares/model-fitting context against Boyd and Vandenberghe's author-maintained applied-linear-algebra material, the descent-method update/stopping boundary against their unconstrained-optimization material, and the external least-squares oracle against official NumPy 2.5 =linalg.lstsq= documentation. Statistical generalization, probability, information theory, multivariate/regularized regression, broad optimization theory, decompositions, and later-project research remain open.
* Phase 2 -- curriculum
IN-PROGRESS review sequence and cross-book dependencies while executable chapter/project slices are written. The current sequence preserves arithmetic/functions/coordinates before vector algebra, matrices/transformations before calculus-heavy projects, and a bounded one-feature regression checkpoint immediately after the calculus foundation so the reader completes one full derive -> optimize -> independently check -> evaluate loop before moving into probability.

* Phases 4--6 -- progressive chapters/projects
IN-PROGRESS implement projects in the order listed in PROJECTS.org; later projects depend on foundations from earlier ones.

Project 1 checkpoint A is the accepted and merged vector semantic baseline: validated finite vectors, component-wise operations, dot product, Euclidean norm/distance, normalization, cosine similarity, projection, NumPy oracle tests, numerical failure cases, and a reproducible projection diagram.

Project 1 checkpoint B is accepted and merged through PR #60 as canonical merge commit =f6ba7459fba79e02dfec6d6129e85b5c60af14b3=. It adds a rectangular finite-real matrix layer, independent row/column interpretations of =Ax=, matrix composition, identity and linearity invariants, selected NumPy oracle checks, explicit mismatch/overflow failures, a deterministic basis/unit-square transformation diagram, and an executable underflow case showing why exact algebraic associativity does not imply bit-for-bit associativity of floating-point execution. This checkpoint does not claim later solving/decomposition/calculus/optimization work.

Chapters 9--12 / the calculus-and-gradient-checking checkpoint are accepted and merged through PR #74 as =3ed0e6f9d5f36927b1cff143da43f5bc4edf1711=. The accepted head =82acd5142fcbfa18a9615a182876a5a6d0d21ae3= passed focused =ml-math-book= run =35146043902= and generic =books-ci= run =35146043911=. This milestone derives secants -> derivatives/local linearization -> partial derivatives -> gradients/directional derivatives -> chain rule, and adds bounded finite-difference/affine-MSE gradient checking plus deterministic secant and level-curve figures. It does not claim a fitted model, optimizer convergence, benchmark, or probability work.

The active dependency-ready slice is Project 2 checkpoint A on branch =book/ml-math-project2-regression-fit=. It derives one-feature affine least squares from the accepted MSE/gradient foundation, implements full-batch gradient descent with an explicit immutable trace and stopping state, derives a centered closed-form checker, checks ordinary finite results against pinned NumPy 2.5.0 =linalg.lstsq=, keeps a fixed evaluation split out of fitting, and injects degenerate-feature, excessive-step, exhausted-budget, and non-finite-arithmetic failures. Its deterministic figure combines data/fit/residual geometry with the recorded optimization trace. Repository CI and Editor-in-Chief review remain required before this checkpoint can be accepted.

After Project 2 checkpoint A is verified and editorially accepted/merged, deepen optimization behavior toward Project 3 rather than stuffing all optimizer theory into this first fit. The same derive -> implement -> independently check -> inject failures progression remains mandatory.
