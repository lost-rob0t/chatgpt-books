* Phase 1 -- foundational research
IN-PROGRESS verify theory, current toolchain behavior, canonical implementations, and source bibliography.

Foundation pass A covers the arithmetic-to-vector dependency chain, author-maintained linear-algebra sequencing, the current NumPy numerical oracle, and Python floating-point primitives used by Project 1 checkpoint A.

Foundation pass B covers matrix shape/indexing, =Ax= as row dot products and column linear combinations, compatible =AB= multiplication, composition/identity/noncommutativity/associativity, two-dimensional linear-transformation geometry, and the finite-precision boundary between algebraic associativity and actual floating-point execution. The source record also captures the current NumPy 2.5 =matmul= and =ndarray.shape= behavior used by the oracle tests plus the official Python floating-point guidance used by the numerical failure lab.

Foundation pass C is the active calculus/derivatives research slice. It checks the secant-to-tangent derivative definition and scalar chain rule against MIT OpenCourseWare 18.01SC, partial derivatives/gradients/directional derivatives against MIT OpenCourseWare 18.02SC, and the sampled finite-difference oracle boundary against official NumPy 2.5 =gradient= documentation. The teaching lab keeps exact derivative claims separate from finite-difference TESTED evidence and carries forward the documented Python floating-point step/cancellation boundary.

Probability, information theory, optimization beyond local derivative direction, decompositions, and later-project research remain open.
