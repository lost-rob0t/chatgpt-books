* Phase 0 -- scope
DONE bootstrap purpose, audience, topics, and project boundaries.
* Phase 1 -- foundational research
IN-PROGRESS verify theory, current toolchain behavior, canonical implementations, and source bibliography.

Foundation pass A covers the arithmetic-to-vector dependency chain, author-maintained linear-algebra sequencing, the current NumPy numerical oracle, and Python floating-point primitives used by Project 1 checkpoint A.

Foundation pass B now covers matrix shape/indexing, =Ax= as row dot products and column linear combinations, compatible =AB= multiplication, composition/identity/noncommutativity/associativity, and two-dimensional linear-transformation geometry. The source record also captures the current NumPy 2.5 =matmul= and =ndarray.shape= behavior used by the oracle tests. Calculus, probability, information theory, optimization, decompositions, and later-project research remain open.
* Phase 2 -- curriculum
IN-PROGRESS review sequence and cross-book dependencies while executable chapter slices are written. The current sequence preserves arithmetic/functions/coordinates before vector algebra, then matrices/transformations before calculus-heavy projects.
* Phase 3 -- detailed outline
IN-PROGRESS turn each chapter item into research questions, examples, exercises, and asset requirements. Chapters 1--8 have now been promoted from generic outline prompts into substantial manuscript material with executable Project 1 checkpoints A/B; later chapter outlines remain intentionally broad until their research slices begin.
* Phases 4--6 -- progressive chapters/projects
IN-PROGRESS implement projects in the order listed in PROJECTS.org; later projects depend on foundations from earlier ones.

Project 1 checkpoint A is the accepted vector semantic baseline: validated finite vectors, component-wise operations, dot product, Euclidean norm/distance, normalization, cosine similarity, projection, NumPy oracle tests, numerical failure cases, and a reproducible projection diagram.

Project 1 checkpoint B is now a worker draft awaiting full branch verification/editorial review. It adds a rectangular finite-real matrix layer, independent row/column interpretations of =Ax=, matrix composition, identity and linearity invariants, selected NumPy oracle checks, explicit mismatch/overflow failures, and a deterministic basis/unit-square transformation diagram. It does not claim later solving/decomposition/calculus/optimization work.
* Phase 7 -- capstone
The last project is the major integrated capstone and depends on the previous project/tooling slices.
