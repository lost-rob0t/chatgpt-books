Issue #118 and PR #119 track a bounded first Gradient Descent Visualizer checkpoint. It begins with

=q(theta) = q_* + (a/2)(theta-theta_*)^2=

and derives the exact fixed-step error recurrence

=e_(k+1) = (1 - eta*a)e_k=.

That multiplier is used to derive, rather than merely illustrate, monotone convergence, one-step landing, oscillatory convergence, the neutral two-cycle boundary, and divergence. The implementation keeps the iterative update loop independent from =closed_form_parameter= so each recorded trace point can be checked against the exact recurrence.

The checkpoint then uses the axis-aligned two-dimensional bowl =q(x,y)=0.5*x^2+5*y^2= to show why one global rate can create different behavior in different directions. At =eta=0.18= the coordinate multipliers are =0.82= and =-0.80=: the path contracts while zig-zagging in the higher-curvature direction. At =eta=0.22= they are =0.78= and =-1.20=: the x direction still contracts while the y direction diverges. General rotated quadratics and their Hessian/eigenvalue analysis remain dependency-gated to later chapters.

The standard-library trace engine rejects invalid/non-finite inputs and non-finite intermediate results. The deterministic SVG is generated from the same trace implementation, uses line patterns and marker shapes rather than color alone, and is required to regenerate cleanly in focused CI.

Repository CI on pre-status head =7342e80e829d47473c6e2defccaf6cbabc08e8bb= verified the implementation under CPython 3.14.7 and NumPy 2.5.0.
