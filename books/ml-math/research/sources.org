** NumPy 2.5 documentation
Authority: official NumPy documentation and official NumPy release-news page.
Release evidence: NumPy 2.5.0 was released 2026-06-21. The official news page lists later 2.5.x bugfix releases, including NumPy 2.5.3 on 2026-09-06. Project 1 deliberately pins 2.5.0 as the TESTED numerical oracle; it does not claim 2.5.0 is the newest 2.5-series patch.
URLs:
- https://numpy.org/news/
- https://numpy.org/doc/2.5/reference/generated/numpy.dot.html
- https://numpy.org/doc/2.5/reference/generated/numpy.linalg.vector_norm.html

- https://numpy.org/doc/2.5/reference/generated/numpy.matmul.html
- https://numpy.org/doc/2.5/reference/generated/numpy.ndarray.shape.html
Inspected material: 1-D =numpy.dot= semantics; dimension errors; vector-norm API; numerical comparison support; 2.5-series release chronology; =ndarray.shape= dimension tuples; conventional 2-D =matmul= behavior and the =(n,k),(k,m)->(n,m)= compatibility signature; 2-D/1-D multiplication; mismatch errors; and the =@= operator relationship.
Used by: Project 1's independent vector and matrix numerical oracle. NumPy is deliberately not used to implement the teaching algorithms themselves.
