* Active foundation record
The 2026-09-16 opening pass covers vector/dot-product sequencing, the deliberately pinned NumPy 2.5.0 numerical oracle and its 2.5-series release context, and Python floating-point primitives used by Project 1 checkpoint A.

The 2026-09-16 matrix pass covers matrix shape, matrix-vector multiplication as both row dot products and column linear combinations, compatible matrix-matrix multiplication, composition order, identity, and two-dimensional linear-transformation geometry for Project 1 checkpoint B. It also records the exact current NumPy 2.5 =matmul= and =ndarray.shape= contracts used by the oracle tests.

A follow-up numerical pass records the boundary between exact matrix associativity and finite-precision execution. A tested one-by-one matrix case demonstrates that two algebraically equivalent parenthesizations can produce different stored results when an intermediate underflows; the manuscript now treats that as a debugging/failure lesson rather than silently implying bitwise associativity.

The 2026-09-16 calculus pass covers the secant-to-tangent derivative definition, scalar composition/chain rule, partial derivatives, gradients and directional derivatives, plus the current NumPy 2.5 sampled-gradient finite-difference contract. It deliberately separates exact derivative statements from TESTED finite-difference checks and uses Python's already-recorded floating-point guidance to motivate step-size failure cases. This pass prepared Project 2 without claiming a regression optimizer or trained model.

The 2026-09-16 Project 2 pass covers one-feature affine least squares, a centered stationary-point derivation, explicit full-batch gradient-descent updates and stopping state, NumPy 2.5 =linalg.lstsq= as an independent ordinary-finite oracle, and failure cases for degenerate feature spread, excessive step size, exhausted step budgets, and non-finite arithmetic. Boyd and Vandenberghe's applied-linear-algebra and convex-optimization material anchors the least-squares/descent-method context; executable claims remain bounded to repository tests rather than promoted into general convergence or statistical guarantees.

The 2026-09-16 Project 3 pass deepens the optimization mechanism without jumping ahead to general Hessian/eigenvalue theory. Boyd and Vandenberghe Chapter 9 is used only for documented gradient-descent/descent-method context; the book directly derives the fixed-step scalar quadratic recurrence =e_(k+1)=(1-eta*a)e_k=, classifies its exact regimes, and extends the same recurrence coordinate-wise to an axis-aligned two-dimensional quadratic. The executable evidence is deliberately separate from the derivation: an iterative trace is checked against a closed-form recurrence oracle, and floating-point overflow remains a fail-closed execution boundary under the existing Python documentation record.

Probability, information theory, multivariate/regularized regression, broader Hessian/eigenvalue optimization theory, decompositions, and later-project theory remain open rather than being implicitly declared complete.
