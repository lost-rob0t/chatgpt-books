* Purpose
A serious independent technical book, eventually about 300--700 rendered EPUB pages when depth warrants it. It is not a README expansion or generic tutorial dump.
* Audience
Developers who want to understand, extend, debug, and operate the real StarIntel codebase.
* Prerequisites
General programming; Common Lisp, Prolog, message queues, and databases are introduced where needed.
* Learning outcomes
The reader should be able to explain the core ideas, implement important mechanisms, debug failures, evaluate tradeoffs, and extend the systems built in the major projects.

The EPUB is intended to be sufficient to /grok StarIntel/ rather than merely browse its APIs.  A successful reader should be able to trace a canonical document from source through validation, ingest, RabbitMQ, CouchDB, outbox/event and actor boundaries; distinguish canonical StarLang schema authority from runtime adoption; reason about actor targets versus persistent investigation targets and operations; and add a tested capability without copying or bypassing the platform contracts.

The manuscript therefore begins with =manuscript/reader-orientation-07.org= and ends with =manuscript/glossary-07.org=.  Those two modules are the reader's map for the deeper pinned runtime experiments.

* Current edition boundary
As of 2026-10-05, canonical new StarIntel documents are defined by StarLang =org.starintel/core@1= version =0.10.1=.  The default =starintel-server= branch still carries its older =0.9.1=/=0.9.0= runtime lock, while the tested =0.10.1= server migration is draft PR #313.  The EPUB must always distinguish canonical authority, runtime adoption, historical compatibility, and exact pinned experiments.
