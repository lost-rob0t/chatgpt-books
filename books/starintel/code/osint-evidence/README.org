packet is not a canonical dtype. The two same-name people remain separate;
the relation describes a fictional programme assertion.

exercise input; a real service must obtain authorization from an authenticated
policy system, not from a client-supplied boolean. Relative simulation seconds
and invented grid coordinates are not geographic observations. No actual
StarIntel actor, authentication implementation, geolocation API call, or
production consent/retention enforcement is claimed.

cache replay, revocation, audience, grant expiry, clock/accuracy failures and
non-mutation. Execution status belongs to the exact CI head.
