- =SWI-Prolog Reference Manual: Analysing and Constructing Terms= -- official current manual, retrieved 2026-09-16. Used for ISO =functor/3=, =arg/3=, and ==../2= semantics plus SWI-specific =compound_name_arguments/3= and zero-arity-compound behavior.
- =SWI-Prolog Reference Manual: Examining the program= -- official current manual, retrieved 2026-09-16. Used for =current_predicate/1= and =predicate_property/2= reflection semantics. Project 1 explicitly does not equate runtime predicate visibility with request authorization.
