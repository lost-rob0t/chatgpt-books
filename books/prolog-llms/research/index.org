* Research policy
Research for this book must support falsifiable teaching claims rather than decorative citations. Prefer official SWI-Prolog documentation and source, standards/specifications, original papers, original implementation repositories, and vendor documentation for current API behavior. Secondary material may provide context but must not silently become the authority for version-sensitive claims.

Every research pass records:
- precise question or claim under test;
- retrieval date and source revision/version where available;
- what was DOCUMENTED by the source;
- what was actually TESTED in this repository;
- what remains UNTESTED or EXPERIMENTAL;
- conflicts or negative evidence;
- downstream chapters/projects affected.

Project 1 is now merged through the bounded meta-call/reflection capability boundary. Broader meta-interpreters, planning, and classical symbolic-AI algorithms remain in =books/symbolic-ai-prolog= rather than expanding this foundation indefinitely.

** LLM integration boundary
Project 2A is editorially accepted in substance in PR #105 but remains subject to its current-main merge gate. It provides the deterministic provider-neutral response-data, exact schema/correlation validation, host-owned provenance, and closed Project 1 capability-dispatch boundary on which later integration work depends. ** Neuro-symbolic systems
Issue #124 now supplies the first substantial primary-literature baseline for Part V. The manuscript classifies systems by authority transition, adds a current-2026 interlude on adaptive solver routing and Prolog compilation/repair, derives the formalization bottleneck and bounded verifier-feedback loop, studies Prolog proof/provenance architectures, and defines a replication protocol. Next work should implement dependency-ready teaching labs and select a narrowly pinned Project 5 reproduction target rather than collecting more papers indiscriminately.

Track exact datasets/prompts/providers/versions for any measured result.
