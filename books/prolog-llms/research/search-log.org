Sources inspected:

- official SWI-Prolog module, module-definition, and import sections;
- official SWI-Prolog debugger overview/trace-mode/spy-point documentation;
- official =library(plunit)= package documentation and current source option table.

Result:
- DOCUMENTED: =once/1= commits to the first success; =!/0= prunes choice points within documented scope; if-then-else commits in its condition; =\+/1= is finite-failure control, not universal real-world negation.
- DOCUMENTED: =module/2= plus =use_module/[1,2]= provides explicit namespace/public-interface composition, not a security sandbox.
- DOCUMENTED: the debugger exposes call/exit/redo/fail as the core beginner trace vocabulary; SWI also has additional ports. Debug mode changes optimization/choice-point retention, so traces are not performance measurements.
- DOCUMENTED: PL-Unit accepts =all(...)=, =set(...)=, =nondet=, =fail=, =throws(...)=, and timeout options. When answers are the contract, this book prefers =all= or =set= over merely marking a test =nondet=.
