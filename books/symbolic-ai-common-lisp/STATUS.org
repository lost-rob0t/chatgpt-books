* Symbolic Planner milestone A draft
- Issue #97 / PR #100 derives a positive-precondition STRIPS-style teaching kernel from the already-merged Search and Unification projects. It does not import a second search engine or inspect Project 2's substitution representation.
- States are finite canonical sets of ground symbolic facts. Action schemas expose explicit parameters, positive preconditions, add/delete effects, and nonnegative costs.
